Pico MCP.

Connect Pico to your AI client. Run pseudocode, build flowcharts and test logic circuits with GitHub sign-in.

https://picompiler.pages.dev/app/mcp

Connect Pico

Use an AI client that supports remote MCP connections.

  1. Open your AI client's MCP or app connection settings.
  2. Add the MCP endpoint shown on the left.
  3. Sign in with GitHub and approve the connection.
  4. Ask your assistant to use a Pico tool.

Examples

Once connected, try these prompts with your assistant.

Pseudocode

Use Pico to run this pseudocode:
DECLARE Number : INTEGER
Number ← 5
OUTPUT Number * 2

Flowchart

Create a flowchart that inputs a number,
checks whether it's even or odd,
and outputs "Even" or "Odd".

Logic circuit

Create a half-adder with two inputs.
Use XOR for the Sum output
and AND for the Carry output.

Available tools

pico_run_pseudocode

Execute Cambridge-style pseudocode.

pico_debug_pseudocode

Inspect execution with a bounded trace.

pico_create_flowchart

Create an editable flowchart document.

pico_run_flowchart

Compile and execute a flowchart.

pico_flowchart_to_pseudocode

Convert a flowchart to pseudocode.

pico_create_circuit

Create an editable logic circuit.

pico_simulate_circuit

Evaluate circuit signals for given inputs.

pico_truth_table

Generate a truth table for a circuit.

pico_capabilities

Read supported syntax and runtime limits.

To open a generated flowchart or circuit in Pico, copy the JSON and select Paste JSON in the matching workspace, or save the JSON as a file and use Import.

Questions & answers

Why won't Pico connect?

Check the MCP server URL, then reconnect and sign in with GitHub. Your AI client must support remote MCP servers.

Why can't I see Pico's tools?

Check that Pico is enabled in your AI client, then reconnect.

What if I reach the request limit?

Try again shortly.
