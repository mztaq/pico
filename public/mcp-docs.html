Connect Pico

Pico uses OAuth with GitHub sign-in and the mcp:run permission. Your AI client must support remote MCP servers and OAuth authorization.

  1. Open your AI client's MCP server or custom connector settings. In ChatGPT, use its Apps settings if custom MCP connections are available on your plan.
  2. Add a remote MCP server using https://picompiler.pages.dev/app/mcp. Select OAuth authentication if your client asks for an authentication method.
  3. Follow the sign-in prompt, authenticate with GitHub, review the requested permissions, and approve only if you trust the requesting application.
  4. After the connection succeeds, ask your AI assistant to call pico_capabilities or run a small pseudocode program.
Pico requires a GitHub account but does not require you to share a GitHub access token or an old PICO_MCP_TOKEN with your AI client. Client support and availability vary.

Try a first request

Once connected, ask your assistant:

Use Pico to run this pseudocode:
DECLARE Number : INTEGER
Number ← 5
OUTPUT Number * 2

Expected output: 10. For supported clients, Pico provides the pico_run_pseudocode tool and returns the program's output, variables and instruction count.

Nine available tools

pico_run_pseudocode

Execute Cambridge-style pseudocode.

pico_debug_pseudocode

Inspect execution with a bounded trace.

pico_create_flowchart

Create an editable flowchart document.

pico_run_flowchart

Compile and execute a flowchart.

pico_flowchart_to_pseudocode

Convert a flowchart to pseudocode.

pico_create_circuit

Create an editable logic circuit.

pico_simulate_circuit

Evaluate circuit signals for given inputs.

pico_truth_table

Generate a truth table for a circuit.

pico_capabilities

Read supported syntax and runtime limits.

Flowchart and circuit creation tools return Pico JSON project content for manual import. They do not directly edit your local browser projects.

Limits & access

  • Authentication: GitHub OAuth. No anonymous access.
  • Execution: up to 500 instructions and 40 debug trace entries per request.
  • Input: 32 KiB maximum HTTP request and 16,384 characters of pseudocode.
  • Projects: up to 100 flowchart nodes, 100 circuit nodes, 200 circuit wires, and eight truth-table switches.
  • Rate limiting: Requests are throttled to protect the free-tier service. A 429 response means you reached a temporary limit.
Pico MCP executes or validates the submitted data. It does not grant AI clients access to Pico's user database, email service, deployment credentials or private local files.

Troubleshooting

401 Unauthorized

The OAuth token is missing, expired, or not valid for this MCP resource. Disconnect and reconnect through GitHub sign-in. Do not paste a legacy shared token.

429 Too Many Requests

The server's rate limit has been reached. Retry after the rate-limit window resets.

Connection or consent fails

Confirm your client supports remote MCP and OAuth with PKCE. Check that the server URL ends in /app/mcp, not /mcp-docs.

Tools do not appear

Reconnect the client and check whether the application's MCP permissions are enabled. Some clients and ChatGPT plans do not provide custom MCP connections.
